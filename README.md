## Reflection

### How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

I try to make programs maintainable and readable by breaking code into smaller parts and using comments. The CRUD Python module helped a lot because it separated database work from the dashboard code. This made Project Two easier to manage and reuse. I could use the same CRUD module approach again in future Python projects that use MongoDB.

### How do you approach a problem as a computer scientist? Consider how you approached the database or dashboard requirements that Grazioso Salvare requested. How did your approach to this project differ from previous assignments in other courses? What techniques or strategies would you use in the future to create databases to meet other client requests?

I approach problems by breaking requirements into smaller steps and building one part at a time. For this project, I had to think about both the database and the dashboard, which made it different from other assignments. In the future, I would still start with planning the data structure and queries first, then build the interface around what the client needs.

### What do computer scientists do, and why does it matter? How would your work on this type of project help a company, like Grazioso Salvare, to do their work better?

Computer scientists build systems that help people solve problems and work more efficiently. This matters because good software can save time and reduce errors. In this project, the dashboard helps Grazioso Salvare filter and view shelter data more easily so they can make decisions faster.
